## 1. 研究问题与逻辑链

**核心问题：** 方向性速度不对称如何进入有向路网与定量空间模型，并决定潮汐车道的短期/长期通勤与福利效应；同时量化对称 travel-cost 假设遗漏了什么。

```
描述性事实（全国 / 深圳 / 北京）
    → 有向 travel cost 测量与锁定
    → 固定有向成本（Stage 1）与内生拥堵 QSM（Stage 2）
    → 潮汐政策：短期 / 长期、sorting、政策对比
    → “对称假设遗漏什么” + 现场视频微观证据
    → 文稿与 slides
```

**当前主线 headline（可讨论引用）：**

| 指标 | 数值 | 解读 |
|------|------|------|
| 短期福利 \(\bar W\) | +0.87% | 慢向走廊立即受益 |
| 长期福利 \(\bar W\) | +0.32% | 网络反馈与 sorting 部分抵消后仍为正 |
| 短期通勤 | 下降 | 直接效应主导 |
| 长期通勤 | 接近零 | GE + sorting 抵消直接节省 |
| 走廊慢向（长期，中位） | 约 −13.6% | 局部工程效果仍明显 |
| OD 路径暴露 | 约 56% | 道路通勤流经 treated 走廊的份额 |
