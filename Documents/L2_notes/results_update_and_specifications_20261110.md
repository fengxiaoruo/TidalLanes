> **2026-11-18 注：** 本文的数字是 β_c = 0.25、07–09 点出发 OD 下算的，已被取代。11-13 起主值为 β_c = 0.35，11-11 起 OD 改为全日。当前口径、数字和运行命令见 `DOCUMENT_INDEX.md` 的 “Current mainline” 表。本文仍可用来查各项口径选择的理由。

## 结论

1. **主口径已经定下。** 下面的结果都在这套口径下：
   - OD：2025-05平台数据，早高峰07–09点出发（11-11起主口径改为不限时段的全日OD，见第3节A2；下面的数字仍是07–09点出发的）；
   - 用时：早高峰07–09点；
   - 底网：OSM方案1B；
   - 格网：3 km正方形格网，4邻接；
   - 潮汐车道与拥堵：按格边定义；
   - 拥堵函数：带畅通下限的常数弹性，β_c = 0.25；
   - κ：按谱半径条件取值，1B为1.48。

   每个口径的状态与对照见第3节。
2. **新主线下，潮汐车道top100的福利为 +0.47%（短期）/ +0.33%（长期）。** 每个通勤者短期省23秒；长期因为人口重新分布，用时比基准多12秒，但福利仍为正。潮汐车道不新增车道公里，长期福利达到同走廊双向扩建（新增900车道公里）的96%。
3. **比旧主线小很多，主要因为拥堵弹性。** 旧主线（2022 OD、gate5、anchored λ = 1.1）为 +0.87%/+0.32%。弹性从1.1换成0.25，福利降到约四分之一；换成1B底网，又升到约1.7倍。第2节逐步列出每一步的变化。
4. **拥堵弹性是对结果影响最大的参数。** 数据给出的可信范围是0.08–0.42，取决于函数形式、是格边还是路段、以及工具变量怎么构造。在这个范围内，潮汐福利短期从0.14%到0.81%，长期从0.13%到0.48%。短期福利大致与弹性成正比，长期的反应小一些。第4节详细说明弹性是什么、怎么估计、为什么不用1.1，以及还没解决的问题。
5. **方向性结论在所有口径下都成立，幅度随口径变化。** "短期省时、长期时间回升、福利仍为正"，以及长期政策排序（定向扩建 ≈ 同走廊扩建 > 潮汐 > 均匀扩建），在所有路网、两种函数、两种格网拓扑下都成立。幅度上：
   - 换BPR约×2；
   - 换gate5约×0.6；
   - 改为按道路定义潮汐车道，并用路段层面的弹性（与道路单元口径一致），长期福利几乎不变（4邻接0.34%，8邻接0.31%）。只改定义、不改弹性时约×0.7。
6. **三件事会影响主结果，需要先定。**
   - **背景车流。** 模型的车流只含通勤者，弹性却是对全部车流估计的。11-11的检验显示，非通勤车流在总量上与通勤车流大致成比例，但方向上对称得多：潮汐走廊上全部车流的快/慢方向比为0.48，通勤车流只有0.29。现行做法因此低估快方向被减车道后受影响的车流，潮汐收益偏高（第4.7节）。若背景车流完全固定，有效弹性只有β_c的约0.3–0.5倍，这是下限而不是中心情形。
   - **外部基准。** 百度格对路径查询11-16结束，用来确认1B与1A哪个更接近实际用时。
   - **BPR的模型推导。** 推导完成前，BPR只作对照。

## 4 拥堵弹性：详细说明

### 4.1 模型里的弹性是什么

模型在每条格边上，用车流相对观测状态的倍数更新用时：

dev = (Ξ / Ξ_obs) × (n_obs / n)

其中Ξ是该边的车流，n是车道数，下标obs表示观测状态。主线的用时函数是：

τ = max(f, τ_obs × dev^β_c)

- τ是物理用时，单位为分钟。
- f是畅通下限，取min(τ_ff, τ_obs)。这样观测状态（dev = 1）正好是不动点，模型的基准就是观测数据。
- β_c是拥堵弹性：在下限以上，每条车道上的车流增加1%，用时增加β_c%。
- 潮汐车道通过n起作用：慢方向n加1，dev下降；快方向n减1，dev上升。

为了和Allen-Arkolakis（2022）对照：模型里冰山成本t满足t^θ = τ，所以AA式拥堵弹性λ = β_c / θ。主线β_c = 0.25、θ = 6.83，对应λ = 0.037。

两个对照形式：
- **BPR**：τ = f × (1 + m_obs × dev^b)，m_obs = τ_obs / f − 1是观测状态的拥堵加价。它的局部弹性是 b × m / (1 + m)，随拥堵加价上升，从0升到b。工作日早高峰的局部弹性中位为0.20，和β_c接近；但在最堵的边上更大，而潮汐车道选中的正是这些边。所以BPR下福利约为常数弹性的2倍。
- **anchored（旧主线）**：τ = max(τ_ff, τ_obs × dev^λ)，λ = 1.1。

### 4.2 数据与识别

**数据。**
- 用时：百度路段速度，10分钟粒度，0519–0525一周。
- 车流：联通路网经过记录，全部目的的小汽车出行，同一周。
- 两者在两个层面上汇总：格边（3 km格之间，gate5边，约2,500条）和路段（百度路段，约1.8万段）。
- 只用有百度观测的路段，插补速度不进入回归。

**估计式**（带下限的常数弹性）：

ln t = max{ ln T0, μ_单位 + δ_日期×小时 + β_c ln q }

- T0是每个单位凌晨0–5点的平均用时，作为下限，固定不估。
- μ是单位固定效应，吸收道路本身的差异（车道数、信号、等级）。
- δ是日期×小时固定效应，吸收全市共同的时段冲击。
- 主样本：06–22点。夜间几乎都在下限上，对斜率没有信息，只会把线性估计拉低。

**为什么要用工具变量。** 直接用观测车流q回归有两个问题。
- 拥堵本身会改变车流：堵的时候通过量受限，部分人改时间或改路。所以车流与用时之间的关系不是纯粹的"车多导致慢"。
- 联通车流是样本车流，有测量误差，会把估计拉向0。

**工具变量z。** 把分时OD（谁在什么时间从哪里出发去哪里）按畅通状态下的最短路分配到边上，并按到达各边的畅通用时平移时段。z只取决于出行需求，不取决于该边当时堵不堵、也不取决于实际选了哪条路。
- 第一阶段很强（F在400以上）。
- 按z的十分位分段，第一阶段斜率都在0.20–0.30之间，最高负荷段也没有变平。所以z在高负荷段仍然有效。

IV的估计约为OLS的2倍，与上面两个问题的方向一致。

### 4.3 估计结果

06–22点，需求IV：

| 形式 | 格边 | 路段 | 0–24点（格边） |
|---|---|---|---|
| 线性：ln t对ln q | 0.16 | 0.18 | 0.09 |
| **带下限的常数弹性β_c** | **0.25** | 0.42 | 0.21 |
| BPR指数b | 1.65 | 2.19 | 1.55 |
| BPR早高峰局部弹性中位 | 0.20 | 0.20 | 0.19 |

- **线性与带下限的区别。** 线性形式对时段窗口很敏感：加入夜间后估计减半。带下限的形式把平坦段扣掉，全天与日间只差约15%。主线用带下限的形式，部分原因就是它对样本窗口不敏感。
- **格边与路段的区别。** 路段层面的β_c更高（0.42对0.25）。模型的拥堵作用在格边上，所以主线用格边层面的估计。按道路定义的稳健性里，拥堵作用在路段上，应当用0.42。这样做以后，按道路定义的长期福利（0.342%）与主线（0.333%）几乎相同，看起来格边层面弹性偏低的部分，与格边定义带来的高估大致抵消。
- **为什么带下限的β_c比线性的高。** 带下限的β_c只衡量拥堵段的斜率，线性的λ是平坦段和拥堵段的平均。所以β_c应当和BPR高负荷段的局部弹性比，不应和线性λ直接比。

### 4.4 稳健性

| 检验 | 结果 | 含义 |

| 只用离该边较远的出行构造z（排除6–9 km以内） | 线性λ降约30%–35%（格边0.13→0.08） | λ的可信范围应写成区间；原因可能是近处出行与该边共享局部冲击，也可能是本地车流与过境车流的作用本来不同，目前无法区分 |
| 最严格的路段匹配（剔除平行路、端点偏离等） | IV只降0.00–0.02 | 匹配误差不是弹性偏低的原因 |
| 剔除百度恒值填充的时段 | 路段IV升10%–17% | 恒值是填充值，不是真实的稳定畅通 |
| 剔除超饱和边（13%） | IV从0.16降到0.14 | 超饱和边拉高估计，但不改变量级 |
| 按典型负荷分段 | 局部弹性从<0.5负荷时的0.09升到≥0.9负荷时的0.36 | 拥堵函数是凸的，弹性随负荷上升，支持带下限或BPR形式 |

| 形状图尾部 | 用时只在每条边车流最高的约1%小时回落；堵的小时车流约为q95的85% | 小时数据里看不到通过量下降 |

与文献对照：Almagro et al.（2026）在芝加哥用同样的带下限形式，私家车β = 0.20（IV）。我们用他们的非线性最小二乘做法，格边层面得到约0.15。

### 4.5 为什么不用1.1

1.1来自Barwick et al.对北京的估计，是**速度对密度**的弹性。模型的拥堵式写的是**用时对车流**（每车道），两者不是同一个对象：同样的路况下，密度上升时车流可能不变甚至下降，所以速度对密度的弹性一般远大于用时对车流的弹性。用我们的数据，按模型的口径直接估计，所有规格都远低于1.1；最高的路段高负荷段也只有0.36–0.58。

同口径的外部参照是AA（2022）对西雅图的估计：用时对每车道车流的弹性为0.488（换算到物理用时）。我们的0.25约为它的一半。[TODO：核对AA Seattle δ1 = 0.488的定义是否与β_c完全同口径]

1.1保留为敏感性分析。在1B上用anchored λ = 1.1，潮汐福利为 +2.37%/+0.82%，是主线的5倍（短期）和2.5倍（长期）。

### 4.6 弹性取值对结果的影响

1B、4邻接、按格边，潮汐top100，福利 W̄ 短期 / 长期（%）：

| 弹性 | 来源 | 结果 |
|---|---|---|
| β_c = 0.08 | 远端z的线性下限 | 0.144 / 0.129 |
| β_c = 0.16 | 原z的线性估计 | 0.294 / 0.234 |
| **β_c = 0.25** | **主线：格边，带下限** | **0.467 / 0.333** |

所有运行都收敛，κ都为1.48。
- 短期福利与弹性近似成正比：β_c从0.08升到0.42（约5倍），短期福利升5.6倍。弹性越大，加一条车道省下的时间越多。
- 长期福利的反应小一些：同一范围内升3.7倍。长期里人口会向变便宜的通勤方向移动，弹性越大，这种回填也越强。
- 所以"长期约为短期的70%"只在β_c = 0.25附近成立：β_c = 0.08时长期为短期的90%，0.42时为59%，λ = 1.1时为35%。

### 4.7 还没解决的问题

1. **背景车流（最重要）。** 弹性是对全部车流估计的：回归里的q是所有目的的小汽车车流。模型的Ξ只含通勤者，早高峰约占车流的36%（直接通勤）到46%（含停留的通勤链）。
   - 现在的模型用Ξ/Ξ_obs代替总车流的变化，隐含假设背景车流与通勤车流同比例变化。
   - 如果背景车流在政策下不变，通勤车流变化1%，总车流只变化s%，s是通勤占比。这时模型里有效的弹性是s × β_c，约0.08–0.12，接近第4.6节β_c = 0.08–0.16两行。这是背景车流完全不改路时的下限。
   - 11-11的检验（第3节A3）显示，背景车流在总量上与通勤车流大致成比例，但方向上对称得多。问题因此主要在方向结构，而不只是有效弹性的大小。
   - 哪个假设更合理，取决于背景车流（购物、送人、商务）对用时是否有反应。两个假设都可以写清楚，主线取哪个要和合作者定。
2. **格边还是路段。** 主线用格边层面（0.25），因为模型的拥堵作用在格边上。但格边层面的用时是格内多条路段的汇总，汇总会平滑掉部分拥堵。路段层面的0.42才是道路本身的弹性。按道路定义的稳健性里已经用了0.42。
3. **小时变化与长期均衡。** 弹性用的是同一条边在不同小时、不同日期之间的变化，模型用它来算早高峰均衡在政策下的变化。这假设短期的车流与用时关系可以用到政策后的新均衡上。Almagro et al.做了同样的假设。
4. **标准误。** 带下限模型和BPR没有算标准误，只有点估计。线性IV的标准误按边聚类约为0.01，按18 km空间块聚类约为0.02–0.03。
5. **唯一性。** β_c = 0.42超过了AA充分条件（0.317）。这不说明均衡不唯一，但不能套用AA的定理。
6. **只有一周数据。** 速度与车流都只有0519–0525一周。日期×小时固定效应已经吸收全市共同冲击；但天气、事件这类只影响部分道路的冲击，无法像Almagro那样用多周重复来检验。
