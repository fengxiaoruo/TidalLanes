# 近期进展汇总（2026-11-01至11-09）

## 结论

1. **主线设定已经换完。**
   - OD：2025-05平台数据。
   - 拥堵函数：带畅通下限的常数弹性，β = 0.25，用需求工具变量估计。
   - 底网：OSM方案1B（百度观测路段加300 m以内的短缺口）。OSM 1A作上限对照。
   - 旧主线（gate5路网、anchored式、λ_phys = 1.1）只作历史对照。
2. **新主线下，潮汐车道top100的福利效应比旧主线小得多。**
   - 1B上福利 +0.47%（短期）/ +0.33%（长期），每个通勤者短期省24秒，长期多12秒。
   - 旧主线在gate5上是 +1.11% / +0.43%。
   - 变小主要因为拥堵弹性从1.1降到0.25。换路网的影响是另一个方向：同一函数下，1B约为gate5的1.7倍。
3. **"短期省时、长期时间回升、福利仍为正"这个方向，在所有路网和两种函数下都成立。**
   - 长期政策排序：按q·延误扩建 ≈ 同走廊扩建 > 潮汐 > 车道×1.1 > 均匀扩建。
   - 潮汐车道不新增车道公里，长期效果却达到同走廊扩建的95%左右。
4. **忽略方向会低估潮汐车道的效果，低估多少取决于底网和拥堵函数。**
   - 在两个OSM路网上，用对称输入重估，潮汐长期效应低估约0.1个百分点（约三成）；gate5上几乎为零。
   - 用BPR时，1B上的低估约为一半。
5. **1B上的选边结果稳定。**
   - 用奇数日和偶数日分别选出的100条走廊有88条相同。
   - 选边与评估用同一份数据带来的高估只有0.2%–1.0%（gate5为7.3%）。
6. **1B和两个中心线路由网络此前违反了路径矩阵的谱半径条件。**
   - 11-09以前这三个网络上的所有模型结果都作废。
   - 现在每个网络取满足条件的最小κ，结果已重跑。
7. **均衡的存在性和唯一性还没有证明。**
   - AA（2022）的定理只覆盖纯幂函数拥堵，不覆盖我们的下限形式。
   - Almagro et al. 用的函数与我们的主线相同，但他们的唯一性是假设加数值检查，并且他们的模型没有集聚外部性。
   - BPR的情况更弱：高拥堵边上的局部弹性超过了AA充分条件允许的范围。
8. **外部基准正在采集。** 百度格对路径查询从11-10起连跑5个工作日，11-16结束，结果用来判断各路网用时与实际行程用时的接近程度。

## 2 拥堵函数：估计与选择

**识别方法。** 边层面和路段层面都用小时面板（0519–0525，主窗口06–22点）。
- 固定效应：单位固定效应，加日期×小时固定效应。
- 工具变量z：把分时OD按畅通最短路分配到边上得到的车流。z只取决于谁在什么时间去哪里，不受该边当时的拥堵影响。

**估计结果。**

| 形式 | 边，06–22点 | 路段，06–22点 | 说明 |
|---|---|---|---|
| 线性（ln t对ln q） | 0.16 | 0.18 | 加入夜间后约减半 |
| 带下限的常数弹性β | **0.25** | 0.42 | 主线 |
| BPR指数b | 1.65 | 2.19 | 工作日早高峰局部弹性0.20 |
| 文献对照：Almagro私家车 | 0.20 | | 他们只用时段变化识别 |

**选择带下限的常数弹性的理由。**
- 每条边车流低时，用时基本不变，拥堵只在高负荷段出现。下限把平坦段扣掉，所以对时段窗口不敏感：全天和06–22点的估计只差约15%，线性形式要差约一半。
- 它与Almagro et al.（2026）的设定相同，便于对照。

**三项稳健性检验。**
1. **只用离该边较远的出行构造z**：λ下降约30%–35%。λ的可信范围应写成区间（线性、边层面约0.08–0.16），不写成单一值。
2. **最严格的路段匹配**：IV估计只降0.00–0.02，匹配误差不是弹性偏低的原因。
3. **形状图尾部**：用时只在每条边车流最高的约1%小时出现回落。堵的小时车流约为q95的85%，看不到通过量下降。

**结论。** 所有估计都远低于旧主线的λ_phys = 1.1。1.1是速度对密度的弹性（Barwick et al.），和模型里以车流写成的拥堵式不是同一个对象。

**BPR的处理。** BPR对形状图拟合最好，用需求IV估计的b = 1.65。它的模型推导还没有做（见第6节），暂时只作对照，不进正文。记录在 `bpr_congestion_version_20261108.md`。

## 3 底网：从gate5到OSM 1B

**gate5的问题。** gate5建在百度路网上，百度路网只含主要道路，很多相邻格之间没有直连道路。
- 按联通车流加权，gate5边只承载相邻格车流的66%。
- OSM三级路及以上可以覆盖95%以上。

**两种OSM构造。** 两种都用OSM三级路及以上，并去掉立交层号；后者已抽查，是安全的。区别在于百度没有观测的路段怎么处理：
- **1B**：只保留百度有观测的路段，再补300 m以内的缺口。用时70.6%来自观测，格对用时中观测部分的占比中位86%。代价是缺高速：按车流算，百度只覆盖约25%的高速。
- **1A**：保留全部路段，未观测路段借上下游3跳内的相对速度，借不到的按"道路等级×圈层"填。路网完整，但观测部分的占比中位只有21%。插补的相对速度不分方向，所以1A把方向不对称冲淡了。

**选择。** 1B作主版本，1A作上限对照（11-09确认）。理由是结论应尽量建立在观测数据上。

**各路网的格对用时差别很大。** 早高峰用时对数相关只有0.36–0.59，方向比相关只有0.29–0.41。这一点决定了外部基准（第7节）的重要性。

**两项稳健性。**
- 1A的插补规则对结果几乎没有影响，相关都在0.98以上。
- 1B对缺口长度敏感：缺口从300 m放宽到600 m，方向比相关只有0.74。

## 4 模型条件：谱半径与κ

**问题。** 模型的路径矩阵是A_kl = 1/(κ·τ_kl)。只有当A的谱半径小于1时，(I − A)^{-1}才等于所有路径的加总。11-09以前所有运行都固定κ = 1，没有检查这个条件。

观测用时处的谱半径：

| 网络 | 谱半径 |
|---|---|
| gate5 | 0.51 |
| v3 gate5 | 0.54 |
| OSM 1A | 0.83 |
| OSM 1B | **1.25** |
| 中心线v11路由 | **1.33** |
| 中心线v3路由 | **1.95** |

后三个网络的格边更多、更短，节点出边的1/τ之和超过1。这时(I − A)^{-1}不是正矩阵，结果没有意义。1B此前出现的不收敛、人口塌缩，以及+550%以上的政策效果，都来自这里。

**修正。** 每个网络取满足条件的最小κ：κ = max(1, ρ₁/0.95)，其中ρ₁按最低可能用时min(τ_ff, τ_obs)计算。
- 1B取1.48，中心线v11取1.48，中心线v3取2.17。
- gate5、v3 gate5和1A仍为1，原有结果不变。

**修正的影响。**
- κ从1升到1.5，潮汐福利只降2%–8%。所以各网络之间的差别主要来自路网本身。
- 修正后，1B上加不加锚点车流下限，结果逐位相同，此前加下限只是掩盖了谱半径问题。下限保留为默认设置，作为保护。

## 6 模型推导：AA与Almagro的核对

### 6.1 AA（2022）的定理覆盖了什么

AA主文Proposition 1（第2928页）的设定是：城市模型、强连通的基础路网、θ > 0、λ ≥ 0，拥堵式为纯幂函数 t_kl = t̄_kl · Ξ_kl^λ，其中t是冰山成本。结论是：
- 均衡存在；
- 当α、β都在[−1, 1]内时，若 α ≤ ½(1/θ − λ) 且 β ≤ ½(1/θ − λ)，均衡唯一。

证明在补充附录C.1。它把拥堵式代入后，整个系统化成一个双变量的幂函数方程组（C.1–C.2），指数 a = θλ/(1 + θλ)。存在性用Brouwer不动点定理；唯一性用Karlin–Nirenberg式的界定论证。附录C.2说明，反事实的存在性与唯一性条件和水平系统相同。

**换算到我们的模型。** 我们的拥堵作用在物理分钟m_kl上，且t^θ = m（A_kl = 1/(κ·m_kl)）。所以物理时间弹性β_phys对应AA的λ = β_phys/θ。
- 主线β_phys = 0.25、θ = 6.83时，λ = 0.0366。界限 ½(1/θ − λ) = 0.0549。
- 主线α = 0.05、β = −0.10，两个条件都满足，但α离界限只差0.005。
- 反过来说，在α = 0.05时，AA的充分条件要求β_phys ≤ 1 − 2θα = 0.317。
- 旧主线λ_phys = 1.1对应λ = 0.161，大于1/θ，所以旧主线不满足这个充分条件。

**定理不能直接用于我们的主线，原因有两个。**
1. **下限。** 我们的函数是 max(f, τ_obs·dev^β)，不是纯幂函数。C.1的变量替换依赖幂函数结构，下限使它在折点处不成立。下限以上的部分是纯幂函数，车道数和κ只改变t̄，这部分与AA相同。
2. **车流下限。** dev中的车流比用 max(Ξ, x_f)/max(Ξ_obs, x_f)，在近零车流的边上也是分段的。

可以期待的是：在平坦段，局部弹性为0，拥堵比纯幂函数更弱，所以唯一性条件应当更容易满足。但这只是直觉，不是证明。[TODO：把AA附录C.1逐步推一遍，看下限是否可以通过对每条边取分段幂函数的上下界来处理]

### 6.2 Almagro et al.（2026）换了什么

Almagro et al. 的拥堵式（PDF第26页，式13）是 T = max{T0, A·F^β}，**与我们的主线形式相同**，不是BPR。他们的存在性与唯一性在附录F.5（PDF第73页）。
- **存在性**：均衡定义为出行向量q在单纯形上的不动点q = f(q)。f连续，单纯形紧且凸，由Brouwer定理得到存在。
- **唯一性**：不是证明出来的，而是假设了一个单调性条件：对任意两个不同的q、q′，(f(q) − f(q′))·(q − q′) < 0。他们写明无法证明这个条件，某些拥堵形式会违反它。他们在实证模型里随机抽了数千对q、q′做数值检查，都满足。
- **他们的模型与我们的不同。** 他们的模型没有集聚外部性，地点不内生，只是出行方式与路径选择。他们把唯一性归于"有拥堵、无集聚"。我们有α = 0.05的生产集聚，所以他们的论证不能直接搬过来。

所以Almagro没有提供"换函数形式后定理仍成立"的结果。他们提供的是一套可以照做的办法：用Brouwer证存在性，再假设单调性并做数值检查。

### 6.3 BPR

BPR的局部弹性是 b·m/(1 + m)，m是拥堵加价，取值从0升到b = 1.65。以AA的充分条件β_phys ≤ 0.317作参照，当m > 0.238时局部弹性就超过界限。基准状态下超过的边：1B占31.5%，gate5占35%，1A占22%；局部弹性最高达1.1–1.5。

这不说明BPR下均衡不唯一，因为AA的条件只是充分条件，而且是针对全局常数弹性的。但它说明BPR不能靠"套用AA"得到唯一性。

### 6.4 建议的推导与检查顺序

1. **存在性。** 对两种函数都写出Brouwer论证。两种函数都连续，需要补的是把均衡系统限制在一个紧凸集上的上下界。可参照AA附录C.1的第一部分。
2. **唯一性，数值部分（先做，成本低）。**
   - 多起点：从τ_ff、τ_obs、2τ_obs和随机起点各解一次基准与主要反事实，看是否收敛到同一个均衡。
   - 单调性：按Almagro的做法，随机抽取成对的状态，检查单调性不等式。
3. **唯一性，解析部分。** 先处理常数弹性带下限的情形，看能否沿用AA的界定论证；BPR放在后面。

## 7 外部基准：百度格对路径查询
