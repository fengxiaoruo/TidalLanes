# 格网拓扑与按道路定义政策：全部方案与结果（2026-11-10）

## 结论

1. **主线不改。** 主线继续在模型层面（格边）定义潮汐车道和拥堵，与文献做法一致（AA 2022、Bordeu、Fajgelbaum-Schaal 都在网络的边上定义政策）。按实际道路定义的结果作为稳健性检验记录（用户决定，2026-11-10）。
2. **按道路定义、并用一阶条件选线时，福利约为主线的四分之三。** 主线（4邻接，按格边，top100）为 +0.467%/+0.333%（短期/长期）。按道路定义、处理300 km慢方向道路、对向车道同时减一条时，4邻接为 +0.342%/+0.245%，约为主线的73%。剩下的差距来自格边定义允许在没有对向车道的地方加车道、以及同一路段被多条格边重复计算。之前"约为一半"的说法来自较弱的选线规则，已更正。
3. **按道路定义后，拓扑依赖没有消失，但变小了。** 各自最优选线、300 km时，8邻接比4邻接低约14%（常数弹性：0.294/0.215 对 0.342/0.245）或8%（BPR：0.525/0.290 对 0.572/0.317）。按格边定义时，8邻接约低45%。之前"两种拓扑几乎相同"的结论来自弱选线，已更正。
4. **剩下的差异来自模型的格网路径分配，不是来自选线。** 把同样的实际道路放进两个模型，4邻接模型的福利总是更高（4邻接选出的路：4邻接模型0.342，8邻接模型0.226；8邻接选出的路：0.335对0.294）。原因是两种格网把车流分到实际道路上的方式不同：同样这300 km道路，4邻接模型里经过它们的车流（按通行时间加权）占29%，8邻接模型里占20%。
5. **按道路定义时，弹性应取路段层面的估计；这样做以后长期福利与主线几乎相同。** 道路单元是路段，对应的估计是β = 0.42（BPR b = 2.19），而不是格边层面的0.25（1.65）。用路段层面弹性，300 km时4邻接为 +0.560%/+0.342%，8邻接为 +0.489%/+0.305%；BPR下为 +0.679%/+0.335% 和 +0.614%/+0.306%。主线长期为 +0.333%。
6. **一阶条件可以作为选线规则。** 每个走廊的一阶福利指标（固定基准流量时的 Σ Ξ_e Δln τ_e）与实际短期福利变化几乎成固定比例：同一设定内，比值的变动不超过 ±2%。
7. **用时验证（只算用时，不跑政策）支持8邻接。** 串联用时对路网直接用时的高估，从4邻接的1.50倍降到1.22倍，方向信息也更好。六边形居中，为1.30倍。

下一步：以上作为稳健性写入结果汇总；8邻接与4邻接的路径分配差异（结论4）留作附录诊断，不改主线。

## 1 问题

模型只为相邻格子算边用时，远距离OD由格网串联得到（AA的路径加总）。每条格边的用时，是两格之间接入点到接入点在1B路网上的最短路平均值。检验发现两个问题：

- 串联会高估长行程。4邻接下通勤加权的中位高估为1.50倍，10–20 km为1.73倍。
- 格边和道路不是一一对应。按中心点早高峰路径算，4邻接下每公里道路平均出现在1.9条格边的路径上，8邻接下为4.0条。在一条格边上加车道，只改变分到这条格边的车流。

## 3 用时验证（方案A、B、C、F、G）

比较对象：把格边串起来得到的用时，与在同一1B路网上直接求的OD用时。两边用同一路网，所以检验的只是格网化本身。

| | 4邻接 | 8邻接 | 六边形 |
|---|---|---|---|
| 串联/直接，通勤加权中位（接入点口径 / 中心点口径） | 1.50 / 1.34 | 1.22 / 1.09 | 1.30 / 1.19 |
| 10–20 km | 1.73 / 1.51 | 1.40 / 1.25 | 1.51 / 1.38 |
| 去固定效应后与直接用时的相关 | 0.98 | 0.98 | 0.98 |
| 单时段方向差相关 | 0.45 | 0.64 | 0.43 |
| 早减自由流方向差相关 | 0.69 | 0.73 | 0.69 |

接入点的重复计入使比值高0.11–0.16，其余高估来自格网几何。8邻接去掉了一半以上。

**Almagro等人的做法**（NBER w32185，2026修订版，第3.3.2节与附录F.2，已核对原文）：芝加哥77个社区区为节点，有向边连相邻社区区，路径固定为谷歌地图给出的路线。OD车内用时等于路径上各边用时之和，再乘以按方式估计的修正 ψ = exp(α + β log d)。α、β由泊松回归估计：因变量是谷歌地图用时，各边用时之和作offset，d是直线距离。原因是边模型对短行程拟合好，但高估长行程。我们照此拟合（通勤加权，40 km以内）：4邻接 ψ 在3/10/30 km为0.75/0.58/0.45，8邻接为0.92/0.71/0.56。他们的模型是用时相加，ψ可以直接乘在OD上；AA式路径加总没有这个位置，所以这里只用于验证。

## 4 按道路定义政策与拥堵（方案D、E）

**做法。** 每条格边的道路内容取它的中心点早高峰最短路（与bundle计算车道时用的路径相同）。道路单元是这些路径用到的OSM路段，加上它们的对向车道。对向车道优先取同一对节点的反向路段；没有的话，取中点60 m以内、方向相反（偏差不超过30度）、同一道路等级族的路段。路径上的道路里有77%找到了对向车道（反向路段37%，平行的另一条单行道40%）。

拥堵改为按道路单元计算：

- 格边车流按路径加到道路单元上，X_u = Σ_e D_eu Ξ_e。
- 每个单元的偏离为 dev_u = (X_u / X_u^obs) × (n_u^obs / n_u)。
- 格边用时用该边路径上各单元的时间份额加权：常数弹性下 τ_e = max(下限_e, τ_e^obs Σ_u H_eu dev_u^β)，BPR下 τ_e = 下限_e (1 + 加价_e Σ_u H_eu dev_u^b)。
- 基准时 dev_u = 1，所以 τ = τ_obs，锚点不变。

当每条边就是它自己的道路时（D = H = I），这就是原来的格边公式。检验结果与主线逐位相同（+0.4674%/+0.3327%，每人短期省时23.46秒）。

潮汐车道按道路定义：候选走廊是一条格边的路径，慢方向的路段加一条车道，对向车道减一条。只处理有对向车道、且对向减车道后仍至少剩一条车道的路段。所有经过这些路段的格边都受影响。

### 4.1 选线规则（四种，都记录）

| 版本 | 走廊得分 | 可选走廊 | 状态 |
|---|---|---|---|
| v1 | 路段自身观测延误 Σ X_u (t_AM − t_FF)，慢方向减对向 | 路径80%以上有对向车道 | 弃用：偏向格子中心附近的路段（同一格出发的路径都从中心节点出发，车流在那里叠加） |
| v2 | 主线的格边延误得分 Ξ_e(τ_e^obs − 下限_e)，按时间份额分到路段 | 同上 | 弃用：没有考虑车道数、对向损失和重叠 |
| v3 | 一阶福利：固定基准流量，Σ_e Ξ_e [ln τ_e(现车道) − ln τ_e(加上该走廊)]；每选一个走廊就按新车道状态重算 | 同上 | 被v4取代 |
| v4 | 同v3 | 任何路径中有对向车道的部分（门槛为0） | **采用** |

v3/v4 的得分来自AA的包络结果：流量固定时，福利的对数变化与 −Σ_e Ξ_e Δln τ_e 成正比（A_kl = 1/(κ τ_kl)）。这里 τ 按道路公式精确计算，不做线性化，所以下限、对向车道的损失和多个走廊之间的重叠都计入了。贪心用懒惰更新：取出得分最高的候选，按当前状态重算；如果仍高于下一个候选，就选它。km 预算下另跑一个"每公里得分"排序（标 pk）。

一阶指标与实际短期福利之比，在每个设定内几乎不变（4邻接常数弹性0.184–0.186，8邻接0.209–0.215，BPR类似）。所以一阶指标的排序是可靠的。

### 4.3 交叉检验：同样的道路，放进另一个模型

把一个模型选出的实际路段（按OSM路段编号）原样加减车道，放进另一个模型求均衡（v4，km300pk）：

| | 4邻接模型 | 8邻接模型 |
|---|---|---|
| 4邻接选出的路（301 km），常数弹性 | 0.342 / 0.245 | 0.226 / 0.166 |
| 8邻接选出的路（302 km），常数弹性 | 0.335 / 0.242 | 0.294 / 0.215 |
| 4邻接选出的路，BPR | 0.572 / 0.317 | 0.375 / 0.210 |
| 8邻接选出的路，BPR | 0.574 / 0.313 | 0.525 / 0.290 |

8邻接选出的路里有少数路段不在4邻接的道路层上（不在任何4邻接格边的路径上），放进4邻接模型时这些路段不起作用。

两点结论。第一，同样的道路在4邻接模型里福利总是更高，所以差异来自模型，不来自选线。第二，每个模型自己选的路在自己模型里最好，选线规则本身没有问题。

诊断（4邻接选出的路，常数弹性，固定基准流量）：经过慢方向路段的车流按通行时间加权，4邻接模型占29%，8邻接模型占20%；一阶净收益为0.0185对0.0107。对向车道的损失两边差不多（0.0033对0.0037）。差异主要来自格网路径分配：4邻接把车流集中在较少的格边上，这些格边的路径又集中在主干路上；8邻接的对角边提供了更多绕行路径，同一条主干路分到的车流更少。这是一个解释，还没有用真实道路流量检验。

| 主线：按格边 | 476 | | 0.467 / 0.333 |
