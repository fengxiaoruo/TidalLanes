# BPR拥堵函数版本：设定、估计与待做的模型推导（2026-11-08）

## 结论

主线拥堵函数用带畅通下限的常数弹性（`ce_floor`，β = 0.25，2026-11-08定）。BPR版本（`bpr`，b = 1.65）已经实现、估计并跑通，但模型层面的推导（均衡存在性、唯一性、福利与定价公式）还没有做，所以暂不进入主线，只作对照。推导完成之前，BPR的结果不写进论文正文。

## 1. 设定

两种函数都锚定在观测状态，在每条格边上按"车流相对观测状态的倍数"更新用时：

dev = (Ξ / Ξ_obs) · (n_obs / n)

其中Ξ是边车流，n是车道数。车流比加了下限：max(Ξ, x_f) / max(Ξ_obs, x_f)，x_f取观测车流中位数的1%（2026-11-08定）。畅通下限f = min(τ_ff, τ_obs)，保证观测状态正好是不动点。

- 常数弹性（主线）：τ = max(f, τ_obs · dev^β)
- BPR：τ = f · (1 + m_obs · dev^b)，其中m_obs = τ_obs / f − 1是观测状态下的拥堵加价

BPR只有一个自由参数b。BPR里的a和容量c由观测加价m_obs吸收，不需要单独估计。BPR的局部弹性是b · m / (1 + m)，随拥堵加价m上升；常数弹性在下限以上恒为β。

代码：`data_work/src/model/full_estimation/equilibrium_solve.py`，`_congestion_tau_update`。

ln t = ln T0 + ln(1 + exp(μ_边 + δ_日期×小时 + b · ln q))

## 4. 待做的模型推导

以下几项完成后，BPR才能作为正式的替代规格进入论文：

1. **均衡存在性与唯一性。** 现有模型稿（`Documents/L1_manuscripts/`）里没有存在性或唯一性的论证，任何一种函数都还没有。Allen–Arkolakis（2022）的结果针对常数弹性拥堵；BPR的弹性随负荷变化，需要单独推导，或说明在什么参数范围内可以套用。（2026-11-09已核对：AA的唯一性充分条件是α、β ≤ ½(1/θ − λ)，只针对纯幂函数；以此为参照，BPR在基准状态下有22%–35%的边局部弹性超过界限。见 `progress_note_20261101_20261109.md` 第6节。）
2. **下限带来的折点。** 常数弹性主线的max(f, ·)和车流下限都会让用时函数出现不可导的折点，推导时要处理。这一项主线也要做，不只针对BPR。
3. **福利与边际外部成本。** 边际外部成本等于局部弹性乘以用时：常数弹性是β · τ（下限以上），BPR是b · (τ − f)。福利分解和庇古税公式都要按函数分别写。
4. **定价反事实（P6、P7）。** 现在的实现把税加到τ_ff上。这只在旧的anchored形式max(τ_ff, ·)下等价于收税；在两种新函数下，税会被min(τ_ff, τ_obs)截掉，BPR下还会改变加价项。因此两种新函数暂不跑P6、P7，要先把税单独写进用时函数。
5. **b的结构含义。** 估计用的是路段/边的小时面板，模型用的是早高峰格边均衡。需要说明面板估计的b在多大程度上可以直接用作模型参数（同样的问题对β也存在）。
