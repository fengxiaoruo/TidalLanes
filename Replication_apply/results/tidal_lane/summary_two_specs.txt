SPECIFICATION A: Congestion-inversion (original)
  t_bar_hat[i,j] = (xi_sym_ij / xi_asym_ij)^(-(1+theta*lambda)/theta)
  xi_sym = lanes x (tau_sym/tau_ff)^(1/delta1)  [same lanes, new travel time]
  Congested dir: xi_sym < xi_asym -> t_bar_hat > 1 (cost RISES)
  Uncongested dir: xi_sym > xi_asym -> t_bar_hat < 1 (cost FALLS)
  Interpretation: targets equilibrium flow consistent with symmetric tau,
  holding lanes fixed. Congested direction sees higher model cost because
  fewer vehicles are inferred at the lower (symmetric) travel time.

SPECIFICATION B: Direct travel-time ratio (alternative, epsilon=0.1)
  t_bar_hat[i,j] = (tau_sym / tau_ij)^epsilon   with epsilon=0.1
  Congested dir: tau_sym < tau_ij -> t_bar_hat < 1 (cost FALLS) -- road improves
  Uncongested dir: tau_sym > tau_ji -> t_bar_hat > 1 (cost RISES) -- road worsens
  Interpretation: iceberg cost proportional to travel time (t_bar ~ tau^epsilon).
  Tidal lane physically improves the slow direction, penalizes the fast one.
  Cost reduction hits MANY commuters (congested); cost rise hits FEW (uncongested).
  epsilon=0.1 is conservative; larger epsilon implies stronger travel-time sensitivity.

  chi_hat = 0.9999794363

INTERPRETATION AND IDENTIFICATION NOTE
  The key distinction is what t_bar represents vs tau:
    Spec A: t_bar is derived from equilibrium traffic flows (xi) via BPR inversion.
      In equilibrium, congested roads have LOW t_bar (many commuters tolerate congestion
      because fundamental attractiveness is high). Making the road 'less congested'
      (tau_sym < tau_obs) with fixed lanes implies fewer vehicles, hence HIGHER t_bar.
      This is a counterfactual experiment: 'same capacity, different equilibrium flows.'
    Spec B: t_bar is treated as proportional to physical travel time tau.
      Capacity reallocation makes slow direction faster -> t_bar falls -> more commuters.
      This is a structural capacity-improvement experiment.
  For a true tidal lane policy (physical capacity reallocation), Spec B is more
  appropriate. Spec A captures a different counterfactual (equilibrium flow targeting).
  The choice of epsilon in Spec B is an additional degree of freedom; epsilon=1
  (proportional) is theoretically clean but produces large shocks for highly
  asymmetric pairs (tau_ratio up to 14.76x -> t_bar ratio up to 14.76, which may
  cause convergence issues). Epsilon=0.1 is conservative and clearly shows the sign.
  Recommended: report Spec B (eps=0.1) as the main tidal lane result;
  report Spec A as a robustness check showing sensitivity to specification.
  Run both locally with tol=1e-4 for full accuracy.
