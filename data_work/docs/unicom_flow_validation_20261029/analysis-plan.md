# 分析规则与实际执行

目标：比较既有模型Ξ与联通经过压力的空间排序及方向性，不识别因果效应。

固定规则：模型gate5主线；北京07:00至09:00经过时钟；2025-05-19至23日平衡样本；周末单列；主指标有效经过数；不补零，不按link缩放，不依相关高低改规则。主匹配RN端点距离1至500米、OSM吸附≤10米、排除坐标多层歧义，OSM最短可行路径节点只按起点格、终点格顺序经过。路径长度≤min(3000米，3×端点距离+100米)。

预定敏感性：250米/1米严格匹配，1000米OSM支持匹配，仅端点500米和1000米低置信度匹配；三个计数指标、每日结果。严格样本属于主样本。共同支持集比较、日文件是否简单复制、方向不平衡中位数属于初次计算后的测量诊断，未用于重选主规则。

交付：flow_metrics、direction_metrics、sample_coverage、crosswalk、图表和L2结果memo。保留原模型和所有源输入。当前没有绝对流量缩放或校准任务。
