# 统计比较矩阵

本任务没有因果回归、处理变量、固定效应或IV。所有相关均为描述性外部一致性。

| 比较 | 变量 | 样本与权重 | 不确定性 |
| --- | --- | --- | --- |
| 流量排序 | Xi与有效经过数 | 平衡工作日link，等link权重 | 无向网格对bootstrap，1000次，seed20261029 |
| 水平/变换后Pearson | 原值、log1p | 同一主样本 | 辅助描述，不报告因果p值 |
| 头部重叠 | 各自top10%，数量向上取整 | 同一支持集 | 不用于调参 |
| share差异 | 每侧除本侧总量 | 同一支持集，TV=半数绝对差之和 | 不解释为绝对车辆预测误差 |
| 方向 | 固定正向与反向的log比 | 双向都观测的964对；等pair权重 | 相关与符号一致率 |
| 时间 | 同模型Xi与逐日计数 | 每日可观测支持，样本数分别报告 | 日稳定性不当作独立重复实验 |
| 匹配敏感性 | 五种规则、三种计数 | 版本原支持及共同1738条连接 | 区分样本变化与测量规则变化 |

bootstrap按无向网格对保留两个方向，未覆盖跨pair空间依赖或系统性匹配误差。无逐路段比例拟合，无训练后调优的报告指标。
